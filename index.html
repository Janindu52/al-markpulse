Chrome Installation Guide

How to add this app to your Android home screen

Option 1: Chrome Menu (Instant) Works Everywhere

If Chrome is not showing an install prompt automatically:

  1. Tap the 3 dots menu (⋮) at the top right corner of Chrome.
  2. Tap "Add to Home screen" or "Install app".
  3. Tap "Add". The app icon will appear on your phone home screen!
Opening as Local File (`file:///`)?

Chrome security policy hides automatic app install banners for raw local files. To make it a 100% full native PWA with offline caching:

Host this single file on GitHub Pages, Netlify, or Vercel (100% free, takes 1 min). Once opened via HTTPS, Chrome will show a direct 1-tap install prompt!
